# SpreadWatch — Credit Spread Analyser

**Capstone project, Group 14 — AI-Based Corporate Bond Credit Spread & Rating Migration Analyser**
PGDM (Financial Management), Agentic AI & Advanced Analytics in Finance, Imperial School of Banking and Management Studies, Pune.

**Research question:** *Do credit spreads on Indian corporate bonds move before the rating agencies act?*

SpreadWatch prices every reported corporate bond trade. It recomputes the yield from the traded price and checks it against the yield the exchange printed. It then measures the spread over the matched-tenor government security. Finally, it runs an event study around every downgrade to test whether the spread widened *before* the agency acted. It also builds a rating transition matrix from the agencies' own rating actions and compares the default risk implied by spreads with the default rates that actually occurred.

> Educational use only. Nothing produced by this project is investment advice or a recommendation to buy, sell or hold any security (SEBI (Research Analysts) Regulations, 2014).

## Quick start

```bash
python3.10 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m pytest                       # 58 hand-worked tests - all must pass
python ingest.py --mode sample         # registers / builds the SYNTHETIC sample
python run_pipeline.py --mode sample   # runs the engine -> outputs/sample/
python report.py --mode sample         # annexure HTML + figures
streamlit run app.py                   # the application (works offline)
```

With your real data (step-by-step: **docs/SpreadWatch_Guidebook.docx**; summary: **DATA_COLLECTION.md**):

```bash
python extract.py                      # optional: pull rating actions out of rationale PDFs
python prepare_curve.py                # only if the G-sec curve came as one file per maturity
python ingest.py --mode real           # refuses any file not registered in sources.csv
python run_pipeline.py --mode real
python commentary.py --mode real       # add --llm to let Claude write it (needs ANTHROPIC_API_KEY)
python report.py --mode real
```

## The five layers and the marks they earn

| Layer | Files | What it does | Rubric line |
|---|---|---|---|
| **L1 Ingest** | `ingest.py`, `sources.csv`, `data/` | Loads NSE/BSE trade files, the FBIL G-sec curve and rating actions; maps their column names; refuses any file without a `sources.csv` entry; logs SHA-256 hashes and row counts | Data & ethics (5), data provenance |
| **L2 Extract** | `extract.py`, `rag/` | Rule-based extraction of rating actions (old → new rating, date, issuer, outlook) from rationale documents, with the evidence sentence; TF-IDF retrieval over rationale paragraphs | Methodological choice |
| **L3 Engine** | `engine/`, `tests/`, `run_pipeline.py` | Bond price↔yield (XIRR convention), matched-tenor G-sec interpolation, spreads, the yield validation test, the event study with placebo controls, the cohort transition matrix, multi-year PD and spread-implied PD | Technical execution (10), technical depth (10) |
| **L4 Commentary** | `commentary.py`, `governance.md` | Writes over engine output only; every sentence cites `[E:fact]`, `[S:source]` or `[R:paragraph]`; a verifier drops any sentence with a missing citation or an unsupported number | Tool proficiency, regulatory linkage (5) |
| **L5 Output** | `app.py`, `report.py` | Streamlit app (7 tabs, including a live failure demo and a bond calculator) and a generated annexure with numbered figures | Strategic value (5) |

No language model touches the mathematics. The optional Claude mode in L4 only rewrites sentences, and its output must pass the same verifier as the template.

## About the synthetic sample

`data/sample/` is generated by `make_sample_data.py`. Issuers are called *SYN Issuer NN Ltd*, and every page, chart and table built from it is labelled SYNTHETIC. It exists so the system can be built and demonstrated before the real data is collected (Rule 7 of the capstone brief). **No synthetic number may appear as a finding in the report.** The findings in Chapters 11–12 must come from `--mode real`.
